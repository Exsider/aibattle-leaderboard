### Мобильная таблица (≤640px)
- Убран `table-layout:fixed`, добавлен `table-layout:auto` — колонки тянутся по контенту
- iOS scroll padding: `display:flex` на `.table-wrap` + `::after{min-width:6px}` (стандартный `padding-right` iOS игнорирует)
- Sticky колонки: `#` на `left:6px`, «Участник» на `left:56px` — с отступом от края панели
- Разделитель между sticky-колонками: `border-right:1px solid var(--line)`
- `rank-cell` 30×30px, при ≤500px — 25×25px

### SVG-иконки в бейджах и легенде
- Убраны emoji из легенды «Система начисления» — заменены на SVG-иконки (те же, что в бейджах)
- Новая иконка **sparkle** (`#ico-diamond`) для Аккуратиста — четырёхлучевая звезда с малым акцентом
- Новая иконка **eye** (`#ico-lab`) для Оценки зрителей — глаз с зрачком
- Новая иконка **birds** (`#ico-bird`) для Ранней пташки — 3 крупные + 1 маленькая птицы ёлочкой (зигзаг)
- Порядок легенды: Победитель → Финалист → Оценка зрителей → Ранняя пташка → Аккуратист → В срок → Пересечь черту

### Визуал бейджей
- `border-radius` бейджей: 999px → 8px
- Финалисты: серебристо-серый цвет + пульсирующее свечение (`finalist-pulse`)
- Победители: золотое пульсирующее свечение (`winner-pulse`)
- Аккуратист: цвет изменён с фиолетового на розовый (`#f4a0cc`)
- Бейджи clock/diamond/check: компактные SVG без капсулы и фона (`.bchip-svg`)
- Иконка-бейджи переносятся на новую строку только группой (обёртка `inline-flex` с `flex-shrink:0`)
- Спецноминации (`nom:*`): текст со звёздочкой `★` (не SVG-иконка)

### Логотипы спонсоров
- FLOWWOW и Avito: добавлен `data-no-grey`, JS-подмена серых версий отключена
- Тёмная тема: `filter:invert(1) grayscale(1) brightness(0.65)` через CSS

### Шрифты hero на мобильном
- Заголовок: `clamp(18px, 6.2vw, 28px)` — пропорциональное масштабирование
- Подзаголовок `em`: `0.5em` — привязан к h2, масштабируется пропорционально
- Описание: `clamp(10px, 3.3vw, 13px)`

### Ссылки на работы
- Убраны капсульные кнопки, добавлено подчёркивание как у гиперссылок
